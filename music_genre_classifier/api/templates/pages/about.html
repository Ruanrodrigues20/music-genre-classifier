Music Genre Classifier

Projeto desenvolvido na disciplina de Inteligência Artificial — UFCG · 2025.2

Um sistema completo de classificação de gêneros musicais utilizando técnicas de Machine Learning, com pipeline própria de dados e integração web.

📚 Contexto do Projeto

O objetivo deste trabalho foi aplicar técnicas de aprendizado supervisionado para resolver um problema real: identificar automaticamente o gênero musical de uma faixa de áudio.

A pipeline foi construída do zero, incluindo coleta de dados, pré-processamento, engenharia de features, treinamento, avaliação e deploy do modelo.

🎧 Construção do Dataset

Ao invés de utilizar bases tradicionais como GTZAN, optamos por construir um dataset próprio, coletando manualmente músicas de diferentes gêneros.

Cada faixa passou por:

  • Padronização de duração
  • Conversão de formato
  • Normalização do sinal
  • Organização estruturada por classe

🔎 Extração de Features

Utilizamos a biblioteca Librosa para extrair características representativas do domínio espectral e temporal.

  • MFCC
  • Chroma Features
  • Spectral Centroid
  • Spectral Bandwidth
  • Zero Crossing Rate
  • RMS Energy

🧠 Modelo de Machine Learning

Foi utilizada uma MLP (Multi-Layer Perceptron) implementada com Scikit-learn, avaliando desempenho através de múltiplas métricas.

  • Accuracy
  • Precision
  • Recall
  • F1-score
  • Matriz de Confusão

🌐 Integração Web

O modelo treinado foi integrado a uma aplicação web, permitindo que usuários façam upload de arquivos de áudio e obtenham predições em tempo real.

A aplicação conecta frontend, backend e modelo treinado de forma modular e escalável.
